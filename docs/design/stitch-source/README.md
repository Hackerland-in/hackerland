# Stitch Source Design Export

This directory preserves the source design tokens and guidelines generated from the Google Stitch export ("Omniforge: Global Innovator Ecosystem Platform"):

- `DESIGN.md`: The verbatim design specification defining the Aerospace Maker System tokens (Space Grotesk, Inter, Deep Space Navy `#0A0E17`, Ion Cyan `#00E5FF`, Forge Amber `#FF8A00`, and tactile workshop UI components).

These design foundations are implemented as production tokens and reusable components in `@hackerland/ui` (`packages/ui/`).
