# Knowledge & Discovery API

### `GET /api/ideas`
Retrieve public IdeaLab workbooks and starter prompts with filter tags.

### `POST /api/ideas`
Create or update a 7-stage Stage Zero IdeaLab workbook.

### `GET /api/problems`
Query the Unsolved Problems Library. Supports filtering by UN Sustainable Development Goals (SDG), domain, and difficulty.

### `POST /api/problems/[slug]/claim`
Form an initial builder squad to tackle a specific unsolved problem.

### `GET /api/stories`
Fetch curated Build Journey Archive case studies and Decision Archaeology narratives.
