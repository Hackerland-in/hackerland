# Information Architecture

```
/
├── discover/
│   ├── /problems               # Unsolved Problems Library
│   ├── /stories                # Build Journey Archive (Decision Archaeology)
│   ├── /ideas                  # IdeaLab & Stage Zero Idea Workbook
│   └── /search                 # Global Innovation Graph Search
├── learn/
│   ├── /learn                  # Knowledge Universe & Curricula
│   └── /how-to-start           # 0-to-1 Blueprint Guides
├── build/
│   ├── /manufacturing          # Hardware Fabrication Hub
│   │   ├── /pcb                # Real-Time In-Browser PCB Studio (Schematic/DRC/3D/Gerber)
│   │   ├── /circuito           # Visual Breadboard Simulator
│   │   ├── /falstad            # Interactive Analog/Digital SPICE Engine
│   │   ├── /hdl                # Digital Verilog/VHDL Waveform Simulator
│   │   ├── /iss                # Orbital Mechanics & Space Mission Lab
│   │   └── /physics            # Multibody Dynamics (EV/Drone/Rocket/Car)
│   ├── /labs                   # Deep-Tech Research Labs
│   └── /projects               # Open Hardware & Software Projects
├── collaborate/
│   ├── /projects/[slug]/apply  # Squad Open Role Applications
│   ├── /earn                   # Grants, Bounties & Paid Work
│   └── /feed                   # Live Innovation Activity Stream
└── credentials/
    ├── /passport               # Personal Innovation Passport (Proof-of-Work)
    ├── /u/[handle]             # Public Builder Profile
    └── /leaderboard            # Karma, Fabrication & Peer Review Rankings
```
